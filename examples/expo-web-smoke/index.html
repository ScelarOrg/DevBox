nodepod — expo web smoke

Boots Nodepod, installs a minimal Expo SDK 54 web app, runs npm run web, and iframes the onServerReady URL. Use probe GET after ready to inspect what Metro returns for /, /index.html, and the AppEntry bundle (debug Cannot GET / / resolve errors).

Serve with node examples/serve.js, then open /examples/expo-web-smoke/. Requires a built dist/ (pnpm run build:publish).
